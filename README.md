# المرجع الفني | أكواد الأعطال والكباسات

تطبيق ويب ثابت (HTML/JS بلا اعتماديات) ومستقل تمامًا عن نظام الورشة.

## التشغيل
- محليًا: `python3 -m http.server 8080` داخل المجلد ثم افتح `http://localhost:8080`.
- النشر: ارفع المجلد كما هو إلى أي استضافة ثابتة تدعم HTTPS (Cloudflare Pages / Netlify / GitHub Pages). HTTPS مطلوب للإدارة وPWA.
- التثبيت على أندرويد: من متصفح Chrome اختر «إضافة إلى الشاشة الرئيسية».

## البيانات
- تُحفظ في `localStorage` على كل جهاز، وتعمل دون إنترنت بعد أول تحميل.
- الإدارة: `#/admin`، أنشئ كلمة مرور عند أول دخول (تُخزَّن مجزأة SHA-256 بملح، ولا توجد كلمة ثابتة في الكود).
- الاستيراد: JSON (مصفوفة أو `{faults:[],comps:[]}`) أو CSV بترويسة بأسماء الحقول الإنجليزية (code, brand, model, meaning… / brand, model, gas, volt…). الحقول الإلزامية: أعطال (type, brand, code, meaning)، كباسات (brand, model).
- التصدير JSON/CSV ونسخ احتياطي (آخر 5 نسخ تُؤخذ تلقائيًا قبل أي تعديل جماعي) من صفحة الإدارة.
- السجلات التجريبية موسومة «تجريبي» ويمكن حذفها بزر واحد.

## قيود معروفة (لم تُنفَّذ)
- قفل الإدارة محلي على الجهاز فقط: لا يحمي بيانات مشتركة بين عدة أجهزة. للمزامنة السحابية والصلاحيات الحقيقية يلزم خادم/قاعدة بيانات (مثل Supabase مع Row Level Security) — غير مُنجز.
- لا رفع للصور/الملفات (حقل رابط فقط).
- لم تُشغَّل اختبارات آلية بعد.

## تحديثات الإصدار المستقر
- `core.js`: المنطق القابل للاختبار (بحث، تحقق، استيراد/تصدير، نسخ احتياطي، تخزين). `index.html` يعتمد عليه.
- كل عملية حفظ/حذف/استيراد/استعادة تتم عبر معاملة: إن فشل الحفظ (امتلاء/تعطل التخزين) يُعاد الوضع السابق وتظهر رسالة خطأ بدل نجاح زائف.
- الاستيراد: فحص النوع والحجم (≤2MB) → معاينة (مقبول/مكرر/مرفوض) → اعتماد يدوي. لا استيراد جزئي عند فشل الحفظ.
- النسخة الكاملة (JSON) تحوي `schema` وتاريخ الإنشاء والمفضلة والسجل. الاستعادة: تحقق → ملخص → تأكيد → نسخة من الحالة الحالية → تطبيق ذرّي. الاستعادة من ملف في صفحة الإدارة، ومن آخر 5 نسخ محلية.
- تصدير CSV محمي من Formula Injection (إضافة `'` قبل `= + - @`).
- تحذير قبل مغادرة نموذج فيه تعديلات غير محفوظة، ومنع الضغط المزدوج على «حفظ».
- القيم غير المتوفرة تظهر «غير متاح». لا تُجرى أي تحويلات وحدات تلقائية؛ تُحفظ القيمة كما أُدخلت.
- تحديث الملفات (Service Worker) لا يمس `localStorage`؛ بيانات المستخدم لا تُمسح بمسح الكاش.
- البيانات المحلية لا تُزامَن بين الأجهزة. قفل الإدارة المحلي لا يمنع من يملك أدوات المتصفح من تعديل البيانات.

## الاختبارات
`node run-tests.js` (لا تحتاج اعتماديات). تغطي منطق `core.js` فقط. اختبارات الواجهة وPWA وAndroid تحتاج متصفحًا ولم تُنفَّذ.
